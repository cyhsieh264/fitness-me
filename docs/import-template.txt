# Strict rule: every workout block STARTS with a date on its own line in the
# format YYYY/MM/DD, optionally followed by a session-type tag:
#   2025/05/12 (self)    -> self-training (自主訓練)
#   2025/05/14 (coach)   -> coach class (教練課)
#   2025/05/16 (other)   -> other (球類、團課等)

# The tag applies to the WHOLE block until the next date line. Anything

# Comments are not supported by the parser — strip them before uploading.

# === conventions cheat-sheet ===
# 40kg*10*4              -> 40kg, 10 reps, 4 sets (total weight)
# 8kg each*10*3          -> 8kg per side (per_side weight)
# 空                     -> bodyweight (no weight value recorded)
# 練習槓                  -> empty 20kg barbell. "練習槓+5kg each" = 30kg total
# 黑+綠                  -> band weight, band_info "black+green"
# 30sec*3                -> timed exercise, 30 seconds, 3 sets
# 30sec each side*3      -> per-side timed, 3 sets
# Wod 30:30*N            -> circuit (30s work / 30s rest), N rounds
# 8-12*3                 -> rep range 8-12, 3 sets
# 34-38kg                -> takes the higher value (38)
# (cue text)             -> attached as exercise notes
# 5上 / 9下              -> bench height setting, IGNORED by the parser
# Body observations like "左骨盆較高" -> become user_conditions entries
